# Recipe Keeper — Lesson 2 (Arc A · Server-Rendered)

A monorepo, the same shape every lesson: `backend/` (the Flask + PostgreSQL app in
Docker) and `frontend/` (the React app — **empty until Lesson 7**).

**This lesson:** A REST API with APIFlask — interactive Swagger docs generated from your schemas.

## Run

```bash
cd backend
cp .env.example .env
docker compose up
```

See `backend/README.md` for the per-lesson steps. Each `L2` is the finished state
of Lesson 2 and the starting point for Lesson 3.
