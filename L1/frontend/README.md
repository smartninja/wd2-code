# Frontend — arrives in Arc B

Intentionally **empty until Lesson 7**. The monorepo carries `backend/` and
`frontend/` from Lesson 1 so nothing moves as the course grows.

In **Arc A** (Lessons 1–6) you build the server-rendered app in `../backend`. In
**Arc B** (Lessons 7–10) the React frontend is scaffolded here with Bun + Vite and
talks to that same API.
